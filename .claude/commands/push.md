---
description: 변경 내용을 커밋하고 원격에 푸시한다
---

현재 작업 트리의 변경 내용을 커밋하고 푸시한다.

수행 순서:
1. `git status`와 `git diff`(스테이징된 것 포함)로 변경 내용을 파악한다.
2. 변경이 없으면 그 사실을 알리고 중단한다.
3. 변경 내용을 요약하는 한글 커밋 메시지를 작성한다. 기존 커밋 스타일(간결한 한 줄 요약, 필요 시 본문)을 따른다. `Co-Authored-By` 서명은 넣지 않는다.
4. `git add -A` 후 커밋한다.
5. 현재 브랜치를 원격에 푸시한다. 업스트림이 없으면 `git push -u origin <현재브랜치>`로 설정한다.
6. 커밋 해시와 푸시 결과를 짧게 보고한다.

주의:
- 커밋 메시지는 사용자가 별도로 지정하면 그것을 우선한다($ARGUMENTS 로 전달될 수 있음).
- 훅(hook)이나 서명을 건너뛰는 플래그(`--no-verify` 등)는 사용하지 않는다.
