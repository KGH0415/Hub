# 주간 식단표 자동 업데이트 작업

너는 CTR빌딩 주간 식단표를 읽어 웹 포털의 식단 데이터를 갱신하는 무인(headless) 에이전트다.
아래 지시를 정확히 따르고, 끝나면 무엇을 했는지 한국어 한 줄로 요약해라. 질문하지 말고 스스로 판단해 완료해라.

## 입력
`scripts/.meal-work/` 폴더에 원본 PPTX에서 추출한 식단 사진이 슬라이드별로 들어 있다.

- `slide1/` = **경남신문 엘리시아뷔페** 식단 사진
- `slide2/` = **국민연금 지하1층 아이앤쿡뷔페 / 한국전력 2층 구내식당**(메뉴 동일) 식단 사진

각 슬라이드 폴더에는 원본과 회전본이 들어 있다: `orig.jpg`, `rot90.jpg`, `rot180.jpg`, `rot270.jpg`.
사진이 돌아가 있을 수 있으니 **네 방향 중 글자가 똑바로 읽히는(정방향) 이미지 하나만 골라** 그것으로 판독해라. 다른 회전본은 무시한다.

## 판독 규칙
- 각 사진은 월~금 5일치 표다. 각 요일의 메뉴 항목을 위→아래 순서대로 모두 읽어라.
- **main(대표 메뉴) 선정 규칙**: 밥·국/탕을 제외한 첫 번째 주요리(고기·생선·튀김·볶음 등 메인 요리)를 main 으로 한다.
  단, 첫 줄이 덮밥·볶음밥 등 밥 자체가 메인이면 그 밥을 main 으로 한다.
  삼계탕·반계탕처럼 국물요리가 그날의 특식/대표요리면 그것을 main 으로 한다.
- **side(반찬)**: main 을 제외한 나머지 항목 전부를 원래 순서대로 ` · ` (공백-가운뎃점-공백)으로 이어붙인다. 밥·국도 side 에 포함한다.
- 사진에 `초복 특식`, `특식`, `<특식>` 등 특식 표시가 있으면 해당 요일 main 뒤에 ` (특식)` 을 붙여라. (앱이 "특식" 글자로 배지를 표시한다.)
- 공휴일·휴무일(예: `제헌절`)이면 그 요일은 `main: "<사유> (휴무)"`, `side: ""` 로 둔다.
- 날짜(`date`)는 사진 상단의 요일 헤더에서 읽어 `"7/13"` 형식으로. 요일(`dow`)은 `월 화 수 목 금`.
- 사진 상단 제목의 주간 기간을 읽어 `weekRangeLabel` 을 `"2026년 7월 13일 (월) ~ 7월 17일 (금)"` 형식으로 만든다.
- 만약 어떤 슬라이드에 실제 메뉴 사진이 없고 "업데이트 중" 같은 안내만 있으면, 그 식당의 `week` 는 **기존 meal.json 값을 그대로 유지**하고 요약에 그 사실을 적어라.

## 출력
`src/data/meal.json` 파일을 아래 구조로 **완전히 덮어써라**(Write). 기존 파일의 `site`, `sourceUrl` 값은 그대로 유지한다.

```json
{
  "site": "CTR빌딩",
  "weekRangeLabel": "...",
  "updatedAt": "<오늘 날짜 YYYY-MM-DD>",
  "sourceUrl": "<기존 값 유지>",
  "cafeterias": [
    { "name": "경남신문 식당", "desc": "2층 엘리시아뷔페",
      "week": [ { "dow": "월", "date": "7/13", "main": "...", "side": "..." }, ... 5일 ... ] },
    { "name": "국민연금 식당", "desc": "지하 1층 아이앤쿡뷔페 · 한국전력 2층 구내식당 메뉴 동일",
      "week": [ ... 5일 ... ] }
  ]
}
```

규칙:
- `cafeterias` 는 정확히 2개, 각 `week` 는 정확히 5개(월~금).
- 반드시 유효한 JSON. 주석·트레일링 콤마 금지. UTF-8.
- 먼저 기존 `src/data/meal.json` 을 Read 해서 `sourceUrl`·`site` 를 확인한 뒤 작성해라.

작업이 끝나면 갱신한 주간 기간과 각 식당 월요일 대표메뉴를 한 줄로 요약해라.
